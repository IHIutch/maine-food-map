How should search and filtering compose?

Maine Food Map now has two ways to narrow the list: a filter bar (town, cuisine, price, open now) and a ⌘K search palette. Today they only half-meet: picking a cuisine in search writes a filter, but anything you typed is thrown away, and search always looks at all 526 places even when you're already filtered down to 18. This demo lets you drive three ways of joining them and see which one behaves the way you'd expect. Pick a policy, then press buttons — or run a walkthrough.
